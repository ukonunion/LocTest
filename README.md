# LocTest 1.0.0 — Fabric / Minecraft 26.3

Клиентский мод открывает отдельное окно управления локальным сервером Paper.
Плагины исполняются настоящим Paper в отдельном процессе. Мир Paper хранится
отдельно от одиночных миров Fabric. Fabric-моды на этот сервер не переносятся.

## Установка

1. Нужны Minecraft Java **26.3**, Fabric Loader **0.19.5 или новее** и Java **25**.
   Fabric API этому моду не требуется.
2. Положите `loctest-0.7+26.3.jar` в `mods` своего профиля Minecraft.
3. Запустите игру. Откроется отдельное окно **LocTest** (при необходимости Alt+Tab).
4. Нажмите **Скачать Paper** и скачайте JAR для **26.3** с официального сайта.
   Затем нажмите **Выбрать Paper JAR**. JAR копируется в папку стенда.
5. Через **Добавить плагины** выберите JAR плагинов и их зависимости.
6. Откройте ссылку EULA. Если согласны с условиями, отметьте согласие.
7. Выберите RAM (по умолчанию 2048 МБ для Paper, дополнительно к памяти игры)
   и нажмите **Запустить**. Первый запуск может скачивать библиотеки.
8. Дождитесь статуса **Готов**. В Minecraft: **Сетевая игра → Прямое подключение**,
   адрес **127.0.0.1:25575**.

Мод не скачивает Paper автоматически и не принимает EULA за пользователя.
Выбор JAR проверяет, что архив исполняемый; версию и происхождение сервера
нужно проверить самостоятельно. В консоли Paper выполните `version`.

## Проверка плагинов

- Внизу панели вводите команды консоли **без `/`** и нажимайте Enter.
- `plugins` — список плагинов; `version` — версия сервера.
- `op ВашНик` — выдать себе права для проверки команд плагинов.
- **Дескрипторы** выводит `plugin.yml` / `paper-plugin.yml` из JAR.
  Это проверка наличия дескриптора, а не полноценная YAML-валидация.
- **Отчёт** создаёт `report.txt`: состояние запуска, дескрипторы,
  строки WARNING/ERROR/Exception и сообщения включения/отключения плагинов.
- Полный вывод последнего запуска находится в `session.log`; Paper также
  ведёт свои логи в `logs`. Новый запуск заменяет `session.log`, новый отчёт — `report.txt`.

Статус **Готов** означает, что Paper сообщил об окончании загрузки.
Он не гарантирует, что все плагины включились или правильно работают.
Проверьте лог, затем команды, события, права, сохранение данных и зависимости
в игре. Для автоматических функциональных проверок нужны сценарии конкретных плагинов.
Поиск ошибок в отчёте эвристический: сохраняется до 5000 подходящих строк;
полные stack trace смотрите в логах.

## Папки и управление

Все файлы находятся в `<папка профиля Minecraft>/paperlab/`:

```text
paper.jar          выбранный сервер
plugins/           плагины и их конфигурации
world/             тестовый мир (создаёт Paper)
server.properties  настройки сервера
eula.txt           согласие с EULA после отметки и запуска
session.log        полный вывод последнего запуска
report.txt         последний сохранённый отчёт
panel.log          диагностика окна
```

Сервер слушает только `127.0.0.1:25575`; RCON и query отключены.
Он использует обычную проверку аккаунта (`online-mode=true` по умолчанию).
Если порт занят, остановите другой процесс, использующий его.
Запускайте только доверенные плагины: отдельный процесс не является песочницей.

Для обновления плагина остановите Paper, дождитесь завершения, откройте папку
сервера, удалите старый JAR и добавьте новый. Автоматической горячей перезагрузки нет.
Кнопка остановки посылает `stop`. При закрытии панели она ждёт до 30 секунд,
затем завершает зависший процесс; при принудительном завершении возможно
несохранение последних изменений мира.

Закрытие Minecraft оставляет панель и сервер работающими. Закрывайте панель
для их остановки. Открытие второй панели для той же папки блокируется.
Панель также можно запустить отдельно (из папки с JAR):

```powershell
java -Djava.awt.headless=false -jar loctest-0.7+26.3.jar "C:\MinecraftTests\paperlab"
```

## Сборка из исходников

Нужен JDK 25 с `java`, `javac` и `jar` в PATH. В PowerShell:

```powershell
.\build.ps1
```

Скрипт скачивает официальный Fabric Loader 0.20.1 для компиляции, собирает
мод и выполняет тесты. Loader не встраивается в итоговый JAR. Gradle/Loom
не требуется: мод не ссылается на классы Minecraft и не требует ремаппинга.
Для сборки без сети можно передать `-LoaderJar "путь\fabric-loader-0.20.1.jar"`.

## Проверено при подготовке

Сборка JDK 25 прошла. Автоматические тесты на отдельном Java-процессе проверили:
распознавание готовности, отправку команд, остановку, повторный запуск,
запрет второго запуска, отказ при отсутствующем сервере, обработку аварийного
завершения, запись ошибки в отчёт и чтение дескрипторов плагинов.

**Запуск в Minecraft/Fabric, графическое окно и настоящий Paper 26.3 в этой
среде не проверялись.** Проверка с вашими плагинами также не выполнялась:
их JAR не предоставлены.
